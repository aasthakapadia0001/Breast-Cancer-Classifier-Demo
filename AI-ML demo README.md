# Breast Tumor Classification Demo

An educational machine-learning capstone using scikit-learn's built-in
breast cancer dataset.

## What it does
Accepts 30 numeric measurements and returns a model prediction and
estimated class probabilities.

## Model
Logistic regression with feature standardization in a scikit-learn pipeline.

## Limitations
This is a small educational example, not a medical device. It has not been
validated for clinical use and must not be used for diagnosis or treatment.
